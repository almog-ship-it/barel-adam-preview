# barel-adam-preview

קובץ אחד: `barel-adam-bundle.zip`, חבילת [WordPress Playground Blueprint](https://wordpress.github.io/wordpress-playground/blueprints)
שבונה תצוגה מקדימה של אתר בפיתוח.

הריפו הזה קיים כדי להגיש את הקובץ בכתובת ציבורית עם
`Access-Control-Allow-Origin: *`, מה ש-Playground דורש. אין כאן קוד מקור ואין
היסטוריית פיתוח.

## שימוש

```
https://playground.wordpress.net/?blueprint-url=<URL-encoded zip>&mode=seamless
```

האתר נבנה מחדש בדפדפן של הגולש בכל פתיחה, על גבי SQLite. אין שרת, שום דבר לא
נשמר, ושום דבר לא מגיע לאתר חי.
